# Security Policy

SilentRecall Wave 1 is experimental and has not been independently audited. Do not use production credentials, real customer data or valuable assets.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/vantuann205/silent-recall/security/advisories/new). Do not attach wallet seeds, authority keys, credential JSON or logs containing private witnesses. Include affected commit, reproduction steps using synthetic data, impact and a suggested mitigation.

Only the latest Wave 1 release is maintained. There is no guaranteed response SLA. See [the threat model](docs/threat-model.md) and [privacy boundaries](docs/privacy-model.md).
